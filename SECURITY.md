# Sécurité

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité. Utilisez le
signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a
vulnerability**. Décrivez le problème, la version concernée et, si possible, comment le
reproduire. Vous recevrez une réponse dès que possible ; la correction est publiée avant
que les détails ne soient rendus publics.

## Versions prises en charge

Seule la dernière version publiée reçoit des correctifs : la mise à jour automatique
l'installe sur les postes.

## Modèle de sécurité

Socket Chat est conçu pour un **réseau interne de confiance**. Ce qu'il protège et ce
qu'il ne protège pas encore est décrit dans la section
[« Sécurité » du README](README.md#sécurité).
